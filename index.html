ข้อมูลเอกสารที่ต้องเตรียม สำหรับไฟล์อัพโหลด

1. ฟอร์มลงทะเบียน สามารถคลิกที่ Download ให้ทำการ Download (เลือก File > Download > Microsoft Excel (.xlsx) แล้วบันทึกไฟล์ลงเครื่อง ให้ทำการ ใส่ข้อมูลในไฟล์ลงทะเบียนพร้อมรูปถ่ายให้เรียบร้อย และบันทึกชื่อไฟล์เป็นชื่อทีมที่ลงสมัคร เพื่อใช้ในการ Upload File เพื่อใช้ในการสมัคร

2. โลโก้ทีม เป็นไฟล์ PNG พื้นหลังใส หรือไฟล์ JPG พื้นหลังขาว เท่านั้น

3. เอกสารรับรองสโมสร จากหน่วยงาน หรือ องค์กร ที่จัดส่ง (ต้องมีการรับรองโดยผู้มีอำนาจลงนาม พร้อมตราประทับ) ไฟล์ประเภท PNG, JPG, PDF เท่านั้น

4. หน้าบัตรปชช เจ้าของสิทธิ์ทีม หรือ ผู้สมัคร ไฟล์ประเภท PNG, JPG, PDF เท่านั้น)

5. หน้าสมุดบัญชีธนาคาร เจ้าของสิทธิ์ทีม หรือผู้สมัคร (กรณีผู้สมัครไม่ได้เป็นเจ้าของสิทธิ์ และเป็นผู้รับเงินรางวัล และหรือเงินประกันทีมคืนเองให้เตรียมเอกสาร มอบอำนาจจากหน่วยงาน แนบเพิ่มเติมด้วย โดยภายในเอกสารให้แจ้ง สิทธิ์ผู้สมัครสามารถรับเงินและจัดการธุรกรรมต่างๆ แทนเจ้าของสิทธิ์ทีมได้)

6. เอกสารมอบอำนาจ (เอกสารมอบอำนาจจากเจ้าของสิทธิ์ทีม กรณี หน้าสมุดบัญชีไม่ใช่ของเจ้าของทีม เพื่อใช้รับเงินรางวัล)

ผู้สมัครสามารถ โหลดระเบียบและกติกาการแข่งขันที่ได้ Downloadเมื่อเตรียมข้อมูลเรียบร้อยแล้ว คลิกที่ปุ่ม NEXT(ต่อไป) เพื่อทำการลงทะเบียน
